# Funding

Silta sponsorship currently supports Serrka, the original initiator of
the project.

GitHub: <https://github.com/Sergey2Gnezdilov/>

Sponsorship helps fund work on:

- The Silta runtime prototype.
- Python/Rust boundary experiments.
- Benchmarks and profiling.
- Documentation and examples.
- Community and contributor support.
- Project infrastructure.

## Governance

Sponsorship does not buy control over the technical roadmap.

Major architectural decisions should remain public, RFC-based, and grounded in
working prototypes, benchmarks, and maintainable implementation tradeoffs.

Sponsors may suggest priorities, fund focused work, or support maintenance, but
Silta's architecture and public API should remain accountable to the project
goals documented in `MANIFESTO.md`, `ARCHITECTURE.md`, and `ROADMAP.md`.

## Current Sponsorship Route

GitHub Sponsors is configured through `.github/FUNDING.yml`:

```yaml
github: [sergegnezdilov]
```

The repository Sponsor button will appear after the GitHub Sponsors profile is
approved and sponsorships are enabled in the repository settings.
