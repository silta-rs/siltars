# Proofs Of Concept

This directory contains focused technical proofs for Silta.

POCs should answer narrow architectural questions before the project commits to
large implementation work.

Each POC should define:

- Goal.
- Target architecture path.
- Success criteria.
- Required measurements.
- Explicit non-goals.
- Follow-up questions.
