# Trademark Policy

Draft policy. This document records project intent and should be reviewed before
the project depends on formal trademark enforcement.

The Apache-2.0 license grants copyright and patent permissions. It does not
grant trademark rights.

The Silta name, project identity, logos, and official community channels are
part of the project's identity.

## Allowed Uses

You may truthfully state that a project is:

- Based on Silta.
- Forked from Silta.
- Compatible with Silta.
- Built using Silta.

You may preserve required attribution notices and refer to the original Silta
project roots.

## Restricted Uses

Do not use the Silta name or marks in a way that suggests:

- Your fork is the official Silta project.
- The Silta maintainers endorse your project.
- Your modified distribution is maintained by the original Silta maintainers.
- Your project is affiliated with `silta-rs` without permission.

Materially modified forks should use a distinct name while preserving original
Silta attribution.

## Project Roots

The original Silta project was conceived and initiated by Serge Gnezdilov.

Official project roots:

- GitHub organization: `https://github.com/silta-rs`.
- Initial repository: `https://github.com/silta-rs/siltars`.
