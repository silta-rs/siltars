# Authors And Project Origin

Silta was originally conceived and initiated by Serrka.

Project roots:

- Project name: Silta.
- GitHub organization: `silta-rs`.
- Website: `https://silta.dev`.
- Initial repository: `https://github.com/silta-rs/siltars`.
- Initial bootstrap year: 2026.

## Original Initiator

Serrka is the original initiator of the Silta project and the source of the
initial project vision.

GitHub: <https://github.com/Sergey2Gnezdilov/>

> Write Python. Run Rust.

Silta's founding direction is a runtime-first backend platform where Python is
the developer-facing interface and Rust is the execution runtime.

## Contributors

Silta is intended to grow as an open-source community project.

Contributors retain authorship of their own contributions through Git history,
pull requests, issues, RFCs, and any contributor lists the project maintains in
the future.

## Attribution In Forks And Derivative Works

Forks and derivative works should preserve the original Silta attribution
notices, including the `NOTICE` file and applicable copyright, patent,
trademark, and attribution notices from the source distribution.

Downstream projects may add their own attribution notices for their
modifications, but should not remove or obscure the original project origin.

This attribution policy is intended to preserve the roots of the project while
remaining compatible with the Apache-2.0 permissive open-source license.
